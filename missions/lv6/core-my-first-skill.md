# Lv.6 백지 설계 — 내 업무를 스킬로

이제 진짜입니다. 당신의 실제 업무에서 반복되는 일 하나를 골라 스킬로 만드세요.
템플릿도, 절차도 없습니다. 지금까지 배운 것이 전부입니다.

## 목표
자신의 반복 업무를 다루는 스킬을 하나 설계·제작하고, 실제로 발동시키세요.
(업무 데이터를 가져올 필요는 없습니다 — 스킬은 "방법 지식"입니다)

## 소재가 안 떠오른다면
회의록 정리 방식, 코드 리뷰 체크리스트, 로그/리포트를 읽는 자기만의 순서,
커밋 메시지 규칙, 주간 보고 형식... 뭐든 "매번 똑같이 설명하는 것"이 후보입니다.

## 심사 기준 (스스로 점검하세요)
1. **트리거 명확성** — description에 내가 실제로 할 말이 들어있는가
2. **범위 제한** — 엉뚱한 요청에 발동하지 않게 선을 그었는가
3. **실행 구체성** — 본문이 순서·형식까지 지시하는가

## 검증
- Linux&nbsp;&nbsp;&nbsp;: `./check.sh core-my-first-skill`
- Windows: `check.bat core-my-first-skill`  (또는 `check.bat` 더블클릭 후 id 입력 — 창은 결과 확인 후 닫으면 됩니다)
(스킬 존재 확인 + 확인 질문. 세미나 후 웹 보드의 AI 심사에 description을 제출하면 상세 피드백을 받을 수 있습니다)
