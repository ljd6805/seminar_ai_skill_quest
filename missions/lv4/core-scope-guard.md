# Lv.4 범위 조절 — 오발동 막기

방금 만든 `test-report` 스킬, 잘 발동되나요? 그런데... 너무 잘 발동되면 그것도 문제입니다.

## 목표
`test-report`가 **엉뚱한 요청에는 발동하지 않도록** description을 다듬으세요.

## 절차 (마지막 레시피)
1. 에이전트에게 다음 두 가지를 시켜보고 스킬 발동 여부를 관찰하세요:
   - A. "테스트 결과 리포트 만들어줘" → 발동해야 함 ✅
   - B. "지난 분기 실적 리포트 초안 써줘" → 발동하면 안 됨 ❌ ("리포트"만 보고 낚이면 오발동)
2. B에서 오발동하거나 애매하게 반응한다면, description에 **무엇을 하는 스킬인지**뿐 아니라 **무엇에는 쓰지 않는지**를 명시해보세요.
   예: "...테스트 결과 CSV 집계 전용. 일반 문서/실적 리포트 작성에는 사용하지 않음."
3. 재시작 후 A, B를 다시 확인하세요.

## 성공 조건
- A는 발동, B는 미발동 (직접 확인)

## 검증
- Linux&nbsp;&nbsp;&nbsp;: `./check.sh core-scope-guard`
- Windows: `check.bat core-scope-guard`  (또는 `check.bat` 더블클릭 후 id 입력 — 창은 결과 확인 후 닫으면 됩니다)
(두 가지 확인 질문에 답하면 성장 코드가 발급됩니다)
